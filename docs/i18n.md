# Languages: English, German, Hungarian

The app speaks English (`en`), German (`de`) and Hungarian (`hu`). The language comes from the phone's setting on first start and can be changed in Profile (saved in `sixtysix.locale.v1`).

## How it works

- `app/src/i18n/index.ts`: `useT()` in components (re-renders on a switch), `t()` in stores and other non-React code, `tServer()` for messages the server sends in English.
- Messages live in `app/src/i18n/<locale>/<namespace>.ts`, one file per area of the app, default-exporting a nested object. The key is `namespace.path`, e.g. `shell.tabs.menu`. New files are picked up automatically (no index to edit).
- English is bundled; German and Hungarian load when picked. A missing translation falls back to English.
- **Interpolation:** `t('home.ready', { n: 3 })` with `{n}` in the text. Never build sentences by concatenating pieces; word order differs (Hungarian especially).
- **Plurals:** pass `count`; `x_one` / `x_other` are picked with `Intl.PluralRules`. Hungarian nouns stay singular after numbers ("3 érme"), so its `_one` and `_other` are often the same.
- **Server messages:** acks and REST errors are in English. An area lists the ones it shows under a `server` sub-object, keyed by the English text, with `{x}` for a value: `server: { 'Not your turn': 'Du bist nicht dran', '“{w}” was already said — try another clue': '„{w}“ wurde schon gesagt …' }`. The English file maps each to itself. Show them with `tServer(error)`.
- **Check:** `npm run i18n:check --workspace app` lists keys used in the code but missing in English, keys German or Hungarian lack (or have extra), and placeholders that differ. Keep it at zero. Dynamic keys (`t(\`shell.tabs.${id}\`)`) aren't checked; keep their key lists complete by hand.
- Numbers: `n.toLocaleString(locale)`, not a hard-coded `'en-US'`.

## Not translated here (later phases)

- Quiz questions, answers and verses (`app/src/questions/*.json`): their text already has a per-language slot (`text.en`); German and Hungarian questions are translated in `question-pipeline/i18n/<lang>.json` (+ a name glossary per language). Verse text comes from the newest Bibles that are free to use (`question-pipeline/scripts/fetch-bibles-modern.mjs`, from ebible.org):
  - **German: Schlachter 1951**, © Genfer Bibelgesellschaft, CC BY 4.0.
  - **Hungarian:** New Testament **Biblica® Nyitott Újszövetség** (2021), © Biblica, Inc., CC BY-SA 4.0 (verses shown unmodified); Old Testament **Károli 1908** (public domain), also the fallback where the modern NT numbers verses differently.
  - These credits must be shown in the app (About / Profile).
- Board-game word lists (`shared/src/flockWords.json`, `server/src/spies/words.json`).

## Tone

- Friendly, short, playful; a family game. German uses **du**, Hungarian uses **te** (tegeződés).
- Keep the emoji. Keep button text short: phones are narrow, and German runs ~30% longer.
- German typography: „…“ quotes, – en dash. Hungarian: „…” quotes.
